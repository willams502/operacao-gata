# 🐱 Operação Gata

Jogo narrativo 2D em pixel art desenvolvido com **JavaScript** e **HTML5 Canvas**, com sistema de cenas, diálogos interativos, áudio e persistência local de progresso.

## ✨ Funcionalidades
- Sistema modular de cenas (`js/scenes.js`) e diálogos (`js/dialogue.js`)
- Áudio e efeitos sonoros integrados (`js/audio.js`)
- Persistência de progresso no navegador via `localStorage` (`js/storage.js`)
- Interface responsiva adaptada para diferentes tamanhos de tela

## 🛠️ Tecnologias
- HTML5 & CSS3
- JavaScript (ES6+)
- HTML5 Canvas & Web Storage API

## 🚀 Como executar localmente
```bash
git clone https://github.com/willams502/operacao-gata.git
cd operacao-gata
npx serve .
```

## 📁 Estrutura do Projeto
```text
├── assets/          # Personagens e cenários em pixel art
├── css/             # Estilos e responsividade
├── js/              # Motor do jogo, cenas, diálogos, áudio e storage
└── index.html       # Ponto de entrada
```
